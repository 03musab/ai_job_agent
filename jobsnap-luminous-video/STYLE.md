# JobSnap Luminous Glass — Visual Style Grammar (`luminous-glass`)

Extracted frame-by-frame from the uploaded 32-second reference reel (`videoplayback.mp4` — Zelios / LangEase style) and adapted authentically for **JobSnap (`jobsnap.me`)**.

| Dimension | Grammar Rule |
|---|---|
| **Ground** | Pure luminous cool-white studio canvas (`#F8FAFF`) across the entire 32s film. Zero dark-mode slabs, zero loud pastel blocks. Depth comes purely from soft tinted under-glows (`rgba(59,130,246,0.18)` + `rgba(16,185,129,0.16)`) and crisp hairline borders. |
| **Palette** | Studio white `#F8FAFF`, crisp graphite ink `#0F172A`, luminous sky-cobalt-emerald accent spectrum (`#38BDF8 → #3B82F6 → #10B981`), subtle muted cool gray `#94A3B8` for secondary counters (`/100`, metadata), and solid obsidian `#0E1117` reserved strictly for the pre-click CTA pill and iPhone bezels. |
| **Type** | Single ultra-clean geometric sans-serif (**Plus Jakarta Sans** / **Inter**), predominantly **weight 400–500** (regular/medium — never chunky bold 800!), tight tracking (`-0.03em`). Accent words take crisp luminous blue/emerald (`#2563EB` / `#059669`). |
| **Word Arrivals** | Signature horizontal blur-slide (`opacity: 0 → 1`, `filter: blur(12px → 0px)`, subtle `x: 24px → 0` or `scale: 0.96 → 1`), silky smooth `power3.out` — effortless and airy, never slamming. |
| **Objects** | Translucent frosted 3D glass folder with peeking white cards; 4 iPhone mockups arranged radially around centered type; oversized glowing horizontal pill progress bar (`81/100 → 100/100`); frosted glass checkmark sphere with flat geometric confetti shards; full 3D-tilted SaaS web dashboard (`rotateX` / `rotateY`); 4-corner orbiting card clones; macro floating white list row with black-to-gradient pill CTA; 4-point luminous sparkle star (`✦`). |
| **Connective Tissue** | Continuous camera-like spatial flow: folder click expands into dashboard plane; ribbon sweeps off phone edge directly into progress bar; checkmark sphere morphs into rounded card; clicked dashboard card fans into 4 corners; clicked CTA pill collapses into sparkle star that writes the tagline and reveals the logo. |
| **Scene Changes** | Zero hard cuts, zero heavy wipes. Every transition is an organic spatial/morph seam: scale-blur dissolve (`0–3s`), 3D folder-to-glass-plane zoom (`5s`), radial phone slide-out + ribbon sweep (`10s`), sphere-to-card morph (`14s`), 3D camera pullback & zoom-in (`16s–22s`), pill-to-sparkle collapse (`25s`), sparkle-to-logo resolve (`29s`). |
| **Tempo** | Fast, fluid 32-second launch reel (~2.1 words/s, a major kinetic camera/morph beat every 2–4 seconds). Something glides, counts, tilts, clicks, or morphs on every frame. |
| **Light & Texture** | Luminous soft ambient bloom strictly beneath glass objects and active pills (`box-shadow`), razor-clean vector edges, zero noise/grain, zero retro effects. |
| **Absent on Purpose** | No dark full-screen backgrounds; no heavy black outlines; no chunky black keyword pills in prose; no pastel block wipes; no static screenshots; no serif fonts. |
